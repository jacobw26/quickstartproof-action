# Support

Use [GitHub Issues](https://github.com/jacobw26/quickstartproof-action/issues) for a
minimal synthetic reproduction of an ordinary usage question or bug. Include
the Action version or immutable commit SHA, the two repository-relative input
paths, the result state, and the smallest synthetic excerpt needed to reproduce
the behavior.

Do not post a credential, token, private repository link, customer source,
production response, personal contact detail, or confidential report. Use the
private process in `SECURITY.md` for a suspected vulnerability.

QuickstartProof performs static consistency checks only; support cannot certify
API runtime behavior, availability, security, compliance, or performance.
