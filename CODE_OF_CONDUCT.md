# Code of conduct

QuickstartProof contributors are expected to be respectful, specific, and constructive. Harassment, threats, discriminatory conduct, publication of private information, and knowingly unsafe contributions are not acceptable.

Project maintainers may edit, reject, or remove contributions and participation that violate this standard. Security reports must follow `SECURITY.md` and must not expose real credentials or private data.

This standard applies in project spaces and when representing the project elsewhere. Raise ordinary enforcement questions through [GitHub Issues](https://github.com/jacobw26/quickstartproof-action/issues) only when they can be discussed safely in public; never post private or sensitive material.
